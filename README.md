# Rulet Analiz APK

Bu proje, verilen son rulet sayısından hareketle geçmiş veri içindeki frekans ve çark komşuluğu ağırlıklarını kullanarak 3 aday bölge üretir.

## Kullanım
1. Uygulamayı aç.
2. Son gelen sayıyı (0–36) gir.
3. "3 BÖLGEYİ HESAPLA" düğmesine bas.
4. Üç bölge ve merkez adayları gösterilir.

> Bu araç yalnızca istatistiksel analiz içindir. Rulet sonuçlarını garanti edemez ve bağımsız rastgele sonuçları kesin olarak tahmin edemez.

## GitHub Actions
`.github/workflows/build-apk.yml` dosyası Android debug APK'sını otomatik derlemek için eklenmiştir.
